ESPECIFICAÇÃO DE PROTOCOLOS

O Fuxico oferece compatibilidade 100% direta com os dois maiores protocolos de compartilhamento efêmero do ecossistema Unix: The Null Pointer (0x0.st) e rustypaste.

🌐 Compatibilidade Nativa com cURL 🔑 Cabeçalho de Gestão X-Token 🛡️ Validação Estrita de MIME & Subpath Aliasing

0️⃣ 1. Protocolo The Null Pointer (0x0.st)

Envie formulários multipart padrão via POST /:

Campo / Parâmetro Tipo Descrição
file Multipart File Conteúdo do arquivo físico a ser enviado.
url String URL Instrui o servidor a baixar e armazenar o conteúdo de uma URL remota.
shorten String URL Encurta a URL informada e devolve um link de redirecionamento.
secret Flag / Vazio Gera um slug secreto e imprevisível de alta entropia (16 caracteres).
expires Inteiro / String Tempo de retenção em horas (ex: 24) ou timestamp epoch em ms.
oneshot Flag / Boolean Queima-de-arquivo: se enviado, o arquivo se autodestrói logo no primeiro download.

Exemplos com cURL

curl — exemplos 0x0.st 
# Upload com validade de 24 horas:
curl -F 'file=@foto.png' -F 'expires=24' https://fuxico.2lp.in/

# Encurtar uma URL:
curl -F 'shorten=https://codeberg.org/lumenpink/fuxico' https://fuxico.2lp.in/

# Gerenciar / Apagar com a ficha X-Token:
curl -F 'token=<X-Token>' -F 'delete=' https://fuxico.2lp.in/abcde.png

🦀 2. Protocolo Rustypaste

Envie arquivos utilizando cabeçalhos HTTP para configuração:

Cabeçalho / Endpoint Formato Descrição
expire: <tempo> Cabeçalho String de duração: 10m, 2h, 7d, etc.
oneshot: true Cabeçalho Ativa autodestruição após o primeiro download.
filename: <nome> Cabeçalho Sobrescreve o nome do arquivo para download amigável.
DELETE /<slug> Método HTTP Apaga um envio usando Authorization: Bearer <token>.
GET /list Endpoint JSON Retorna lista estruturada em JSON dos envios ativos.

Exemplos com cURL

curl — exemplos rustypaste 
# Upload com cabeçalho de expiração de 10 minutos:
curl -F 'file=@segredo.txt' -H 'expire: 10m' https://fuxico.2lp.in/

# Apagar via método DELETE:
curl -X DELETE -H 'Authorization: Bearer <token>' https://fuxico.2lp.in/abcde.png

# Listar uploads ativos:
curl -H 'Authorization: Bearer <token>' https://fuxico.2lp.in/list

📎 3. Apelidos de Subcaminho (Subpath Aliasing)

Precisa compartilhar um arquivo de modo que ao salvar ele tenha um nome legível em vez de um slug aleatório? O Fuxico suporta subpath aliasing nativamente:

Estrutura de URL com Subpath 
https://fuxico.2lp.in/<slug>.<ext>/<nome_amigavel>

Exemplo: https://fuxico.2lp.in/8x9yt.png/avatar-lumen-2026.png serve o mesmo arquivo definindo o cabeçalho Content-Disposition: inline; filename="avatar-lumen-2026.png".
