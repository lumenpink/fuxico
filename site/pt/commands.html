MANUAL DE COMANDOS (`fux`)

Tanto o binário compilado em Rust quanto o script universal em Bash compartilham o mesmo nome curto (fux), as mesmíssimas opções bilíngues e arquivo de configuração unificado.

💻 Deboche no stderr, URL pura no stdout 📋 Integração com Área de Transferência 🔥 Queima-de-arquivo Oneshot

⚡ A Regra de Ouro da Ergonomia

Deboche, telemetria e fichas de gestão vão para o stderr. A URL pura vai para o stdout.

Essa garantia assegura que o fux nunca quebre seus pipes no shell, scripts automatizados ou área de transferência:

bash — exemplos de clipboard e pipes 
# Enviar e copiar direto pra área de transferência (xclip / wl-copy / pbcopy):
fux foto.png --copia

# Atribuir a URL limpa direto para uma variável de shell:
url=$(fux relatorio.pdf --caladinho)

# Enviar saída de comando direto como link efêmero de queima-de-arquivo:
dmesg | fux -q | xclip -selection clipboard

# Publicar anotação em Markdown como página Zine com realce de sintaxe:
fux memo.md --doc

# Publicar Gist com múltiplos arquivos de código (com abas e download ZIP):
fux gist src/main.rs Cargo.toml README.md

# Criar repositório Git bare remoto instantâneo via HTTP smart protocol:
fux git init meu-projeto

🎛️ Tabela de Flags e Opções Bilíngues

O Fuxico oferece paridade bilíngue total. Você pode misturar opções em português ou inglês à vontade:

⚙️ Arquivo de Configuração Unificado

Defina os valores padrão para os clientes em Rust e Bash em ~/.config/fux/config.toml:

~/.config/fux/config.toml 
# URL do servidor
server = "https://fuxico.2lp.in"

# Token mestre (para instâncias privadas) ou token padrão
# token = "seu-token-secreto"

# Dialeto padrão (nullpointer ou rustypaste)
dialect = "nullpointer"

# Tempo de retenção padrão
expires = "24h"

# Queima-de-arquivo por padrão
oneshot = false

# Copiar automaticamente para o clipboard
clipboard = true

🔄 Compatibilidade com Clientes Externos

Já usa rpaste (rustypaste-cli) ou 0x0? Eles funcionam imediatamente com o Fuxico:

rustypaste-cli (rpaste)

Exporte a variável ou configure ~/.config/rustypaste/config.toml:

export RPASTE_SERVER="https://fuxico.2lp.in"

Depois use os comandos normais:

rpaste foto.png -o -e 2h

Cliente 0x0.st (AndyRusso / olavfosse)

Aponte para a instância do Fuxico:

export NULLPOINTER_URL="https://fuxico.2lp.in"

Compatibilidade total com headers de token e deleção:

0x0 -s -e 48 documento.pdf
