ESPECIFICAÇÃO DE PROTOCOLOS

O Fuxico implementa 5 protocolos principais de comunicação: The Null Pointer (0x0.st), rustypaste, Publicação Zine em Markdown, Gists Multifiles e Git HTTP Smart Protocol.

🌐 Compatibilidade Nativa cURL & Git 🔑 Cabeçalho de Gestão X-Token 📝 Markdown, Gists & Repositórios Bare

0️⃣ 1. Protocolo The Null Pointer (0x0.st)

Envie formulários multipart padrão via POST /:

Campo / Parâmetro Tipo Descrição
file Multipart File Conteúdo do arquivo físico a ser enviado.
url String URL Instrui o servidor a baixar e armazenar o conteúdo de uma URL remota.
shorten String URL Encurta a URL informada e devolve um link de redirecionamento.
secret Flag / Vazio Gera um slug secreto e imprevisível de alta entropia (16 caracteres).
expires Inteiro / String Tempo de retenção em horas (ex: 24) ou timestamp epoch em ms.
oneshot Flag / Boolean Queima-de-arquivo: se enviado, o arquivo se autodestrói logo no primeiro download.

Exemplos com cURL

curl — exemplos 0x0.st 
# Upload com validade de 24 horas:
curl -F 'file=@foto.png' -F 'expires=24' https://fuxico.2lp.in/

# Encurtar uma URL:
curl -F 'shorten=https://codeberg.org/lumenpink/fuxico' https://fuxico.2lp.in/

# Gerenciar / Apagar com a ficha X-Token:
curl -F 'token=<X-Token>' -F 'delete=' https://fuxico.2lp.in/abcde.png

🦀 2. Protocolo Rustypaste

Envie arquivos utilizando cabeçalhos HTTP para configuração:

Cabeçalho / Endpoint Formato Descrição
expire: <tempo> Cabeçalho String de duração: 10m, 2h, 7d, etc.
oneshot: true Cabeçalho Ativa autodestruição após o primeiro download.
filename: <nome> Cabeçalho Sobrescreve o nome do arquivo para download amigável.
DELETE /<slug> Método HTTP Apaga um envio usando Authorization: Bearer <token>.
GET /list Endpoint JSON Retorna lista estruturada em JSON dos envios ativos.

Exemplos com cURL

curl — exemplos rustypaste 
# Upload com cabeçalho de expiração de 10 minutos:
curl -F 'file=@segredo.txt' -H 'expire: 10m' https://fuxico.2lp.in/

# Apagar via método DELETE:
curl -X DELETE -H 'Authorization: Bearer <token>' https://fuxico.2lp.in/abcde.png

# Listar uploads ativos:
curl -H 'Authorization: Bearer <token>' https://fuxico.2lp.in/list

📎 3. Apelidos de Subcaminho (Subpath Aliasing)

Precisa compartilhar um arquivo de modo que ao salvar ele tenha um nome legível em vez de um slug aleatório? O Fuxico suporta subpath aliasing nativamente:

Estrutura de URL com Subpath 
https://fuxico.2lp.in/<slug>.<ext>/<nome_amigavel>

Exemplo: https://fuxico.2lp.in/8x9yt.png/avatar-lumen-2026.png serve o mesmo arquivo definindo o cabeçalho Content-Disposition: inline; filename="avatar-lumen-2026.png".

📝 4. Publicação Zine em Markdown

Envie documentos Markdown padrão para publicar leitores web autônomos com realce de sintaxe, suporte a Obsidian e alternador de tema:

Campo / Requisição Formato Descrição
POST /api/doc ou POST / (doc=true) Multipart Envia arquivo Markdown e aciona a compilação atômica do leitor HTML.
GET /<slug> Negociação de Conteúdo Navegadores recebem o leitor HTML estilizado; chamadas via curl recebem o Markdown cru puro.
GET /<slug>?raw=1 Texto Puro Força explicitamente a entrega do conteúdo Markdown fonte intacto.
POST /<slug>/assets Multipart Envia imagens ou anexos vinculados a /<slug>/assets/<arquivo>.

Exemplo com cURL

curl — publicação de markdown 
# Publicar nota Markdown como documento Zine autônomo:
curl -F 'file=@artigo.md' -F 'doc=true' https://fuxico.2lp.in/

📦 5. Protocolo de Gists Multifiles

Envie múltiplos trechos de código em uma única requisição JSON via POST /api/gist. O Fuxico compila um visualizador em abas e gera endpoints de código cru e arquivo ZIP:

cURL — criar gist com múltiplos arquivos 
curl -X POST https://fuxico.2lp.in/api/gist \
  -H "Content-Type: application/json" \
  -d '{
    "files": [
      { "name": "main.rs", "content": "fn main() { println!(\"olá!\"); }" },
      { "name": "Cargo.toml", "content": "[package]\nname = \"demo\"\nversion = \"0.1.0\"" }
    ],
    "expires": "7d",
    "oneshot": false
  }'

Endpoints Disponíveis:
• Leitor Web: https://fuxico.2lp.in/<slug> (Visualizador com abas interativas)
• Arquivo Cru (raw): https://fuxico.2lp.in/<slug>/raw/<nome_arquivo> (Conteúdo individual do arquivo)
• Pacote ZIP: https://fuxico.2lp.in/<slug>/zip (Download de arquivo ZIP com todos os arquivos do gist)

🌱 6. Git HTTP Smart Protocol

Hospede repositórios Git remotos efêmeros ou permanentes sobre HTTP padrão, sem necessidade de servidores SSH dedicados:

bash — ciclo de vida Git HTTP 
# 1. Inicializar repositório bare remoto via CLI:
fux git init meu-projeto

# 2. Adicionar o remote ao seu repositório git local:
git remote add fuxico https://<FICHA>@fuxico.2lp.in/<slug>.git

# 3. Enviar commits:
git push fuxico main

# 4. Clonar de qualquer terminal:
git clone https://fuxico.2lp.in/<slug>.git
